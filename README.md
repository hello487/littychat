# Litty Chat

---

## ⚠️ 仓库说明
**本仓库仅为纯客户端**，不含任何后端服务、接口、云端数据库逻辑。  
后端代码我会单独放在另一个独立仓库，采用**前后端完全分离**模式，各自独立维护、独立部署。


---

## 🛠️ 项目技术
- 核心框架：Electron
- 前端：原生 HTML / JS
- 本地数据库：sql.js
- 打包：electron-builder

---

## 📋 运行要求
- 安装 Node.js 16 及以上版本
- 无需额外搭建本地后端
- 需自行对接后端接口才可完整使用登录、AI对话等功能

---

## 🚀 本地运行
```bash
# 克隆项目后进入根目录
npm install
npm start
